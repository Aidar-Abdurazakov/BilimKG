# BilimKG — школьная платформа (Django + PostgreSQL)

## Первый запуск (Mac)
```bash
cd BilimKG
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # затем откройте .env и заполните настройки

# PostgreSQL (если ещё не стоит)
brew install postgresql@16 && brew services start postgresql@16
createdb bilimkg            # или: psql -c "CREATE DATABASE bilimkg;"

# Откройте .env и впишите DB_USER / DB_PASSWORD от вашего PostgreSQL
python manage.py migrate    # создаёт таблицы и все предметы 5–11 классов
python manage.py seed_demo  # демо-школа и демо-материалы (по желанию)
python manage.py runserver
```
Сайт: http://127.0.0.1:8000/  (переключатель языка РУ / КЫ — вверху справа).

Демо-аккаунты после `seed_demo` (пароль у всех Demo12345):
`admin.direktorov` (админ школы), `aygul.asanova` (учитель), `bekzat.turgunov` (ученик 7А).

## Как устроены школы и роли
- **Владелец платформы** (superuser, `python manage.py createsuperuser`) заходит в /admin/ только чтобы создать школу. Быстрее командой:
  `python manage.py create_school "Школа №1" "Асанов Азамат"` — выдаст логин и временный пароль админа школы.
- **Админ школы** работает прямо на сайте (раздел «Школа»): добавляет учеников и учителей по одному или списком класса (вставка из Excel/Word), выдаёт новые пароли, отключает аккаунты, создаёт темы, тесты и контрольные, видит успеваемость.
- **Учитель**: создаёт темы, тесты (с вопросами и дедлайном для класса), контрольные; проверяет работы по фото, ставит оценки 2–5.
- **Ученик**: читает темы, проходит тесты (оценка автоматически), сдаёт фото контрольных. Видит только свой класс и свою школу.
- Новый пользователь входит с временным паролем и при первом входе сам придумывает свой.
- Предметы 5–11 классов общие для всех школ (добавляются миграцией). Материалы, созданные школой, видны только этой школе.

## Настройки (.env)
Перед первым запуском скопируйте `.env.example` в `.env` и заполните секреты и настройки базы данных. Файл `.env` игнорируется Git и не включается в архив проекта.
Для боевого сервера: `DEBUG=False`, `ALLOWED_HOSTS=ваш-домен`, HTTPS, SMTP (`EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend`, `EMAIL_HOST` и т. д.). Пока почта не настроена, письма «забыли пароль» печатаются в Терминале; ученикам без email пароль выдаёт админ школы.
`DB_ENGINE=sqlite` в `.env` — быстрый тест без PostgreSQL.

## Языки
Русский и кыргызский: тексты интерфейса в `locale/ky/LC_MESSAGES/django.po` (готовый `.mo` уже есть). Названия предметов — в полях `title` / `title_ky`.
Материалы (темы, тесты) показываются на том языке, на котором их написал учитель.
